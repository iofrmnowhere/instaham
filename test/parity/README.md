# Model-Parity Testing Protocol (§14)

Model-parity tests compare the on-device inference pipeline against reference outputs generated by the Python training pipeline.

## Required Fixtures

When final models are selected, export reference test fixtures to `test/fixtures/parity/`:

1. `fixtures/parity/test_images/`: Held-out validation images (JPEG/PNG).
2. `fixtures/parity/ground_truth.json`: Reference predictions containing:
   - View classifier probabilities & predicted label
   - YOLO segmentation instance masks & confidences
   - Health classification probabilities & predicted class
   - Extracted morphological features (`RA`, `LC`, `BL`, `BW`, `E`)
   - XGBoost final weight predictions (kg)

## Target Numerical Tolerances (§14)

Before release, outputs must match within the following bounds:

| Metric | Target Tolerance |
|---|---|
| View classifier confidence | ±0.01 absolute |
| Health classifier confidence | ±0.01 absolute |
| Features (`RA`, `LC`, `BL`, `BW`, `E`) | ±0.5% relative error |
| Weight prediction (`kg`) | ±0.5 kg absolute |

## Execution

Once model weights and fixtures are available in the repository:
1. Remove `skip: 'Needs concrete ML service'` from `test/parity/parity_test.dart`.
2. Run `flutter test test/parity/parity_test.dart`.
