# Phase 2 toolchain — what was installed, and how to remove it

Everything on this page was installed during the phase 2 session (porting the V176/V144
cutter) purely to get a **host C++ build** working. This machine had no C++ compiler at all
before that. None of it is needed to run the app — the Android build uses the Android SDK/NDK,
which was already here and is **not** listed below.

Sizes measured at time of writing. Nothing here is committed to git.

## Outside the project folder (system-wide)

| What | Where | Size | Remove with |
|---|---|---|---|
| Visual Studio Build Tools 2022 (C++ workload + Windows SDK) | `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools` | 3.34 GB | `winget uninstall --id Microsoft.VisualStudio.2022.BuildTools` |
| vcpkg + its OpenCV build | `C:\vcpkg` | 3.38 GB | Delete the folder: `Remove-Item -Recurse -Force C:\vcpkg` |

**~6.7 GB total.** Neither writes anything into the project folder.

Notes:

- The Build Tools install pulled the Windows 10/11 SDK (10.0.26100) as a recommended
  component. The winget uninstall removes it along with the rest.
- Inside `C:\vcpkg`, 2.8 GB of the 3.38 GB is throwaway cache — `buildtrees\` (2.11 GB) and
  `downloads\` (0.68 GB). If you want to *keep* a working OpenCV but reclaim most of the
  space, delete just those two subfolders; `installed\` (0.23 GB) is the part CMake actually
  links against.
- The only vcpkg package installed was `opencv4[core]:x64-windows` 4.12.0. It pulled `zlib`
  as a dependency, plus vcpkg's own msys2/pkgconf helper tools into `downloads\tools\`.
- Deleting either of these breaks the host `ctest` build (see `docs/handoff.md` for the
  configure command that depends on them). The Android build is unaffected.

## Inside the project folder

| What | Where | Size | Safe to delete? |
|---|---|---|---|
| Python packages added to the existing export venv | `.venv-export/` | 556 MB total | Yes, but the venv predates this session — see below |
| Host CMake build output | `packages/instaham_ml_ffi/src/build/` | 98 MB | Yes, regenerated by re-running cmake |
| Android native build cache | `packages/instaham_ml_ffi/android/.cxx/` | 245 MB | Yes, regenerated by the next Android build |
| Flutter build output incl. the debug APK | `build/` | 4.8 GB | Yes, regenerated by the next `flutter build` |

All four are gitignored. `packages/instaham_ml_ffi/src/build/` was added to `.gitignore` during
this session; the other three were already there.

**About `.venv-export/`:** the venv itself was created in an *earlier* session, not this one —
don't delete it on this page's account. This session only added packages into it:
`opencv-python-headless` 5.0.0.93, `scikit-image` 0.26.0, and scikit-image's dependencies
`imageio` 2.37.4, `tifffile` 2026.8.23, `networkx` 3.6.1, `lazy-loader` 0.5. (`scipy` 1.18.1
was already installed by a previous session.) These are what
`ML/parity/chen16_feature_port_gate.py` needs to run the Python side of the feature comparison.

## Quick full teardown

Only once the project no longer needs a host C++ build:

```powershell
winget uninstall --id Microsoft.VisualStudio.2022.BuildTools
Remove-Item -Recurse -Force C:\vcpkg
Remove-Item -Recurse -Force "packages\instaham_ml_ffi\src\build"
```
